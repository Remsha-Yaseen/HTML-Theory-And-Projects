# 🚀 Project

This is a web project built as part of my CS foundation journey. It focuses on **HTML boilerplate, creating diff forms/catalog, review a movie page and applying multimedia player**.


## 🛠️ Technologies Used
* **HTML5** – For the structure and semantic elements all in mentioned in Theroy files.


## 🌟 Key Features
- [ ] Responsive design (works on mobile).
- [ ] Clean and semantic HTML code.
- [ ] A structured content page utilizing semantic tags to review and rate cinema.
- [ ] Embedded video and audio players to create a dynamic, rich-media experience.



## 🧠 What I Learned
During this project, I practiced:
1. **Structural Integrity:** Mastered the HTML5 Boilerplate, understanding how the <head> (metadata) and <body> (content) work together to create a functional webpage.
2. **Data Collection & Layouts**: Learned how to use <form> elements and input types to gather user data and how to structure a product catalog using organized lists and semantic tags.
3. **Semantic Storytelling:** Practiced using semantic tags (like <article>, <section>, and <aside>) while building the Movie Review page to make the code more readable for search engines and screen readers.
4. **Media Management:** Gained experience embedding and controlling <video> and <audio> tags, ensuring that the multimedia players are responsive and user-friendly.
5. **File Architecture:** Improved my workflow by organizing complex projects into dedicated folders for better maintainability on GitHub.

## 🚀 How to Run the Project
1. Download the files or clone the repository.
2. Open the `.html` file in any modern web browser.
